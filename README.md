# Vortex
Classic arcade game maelstorm clone in SDL2 + Vulkan

Try to make something fun while learning vulkan (again), hopefully I can finish a project this time lol

Thirdparty dependencies (put the headers and libs under ./thirdparty/include & ./thirdparty/lib):
 - SDL2 2.30
 - VulkanSDK 1.3
 - glm
 - VulkanMemoryAllocator 3.0.1
 - imgui 1.90.4
